# Agent Market Dashboard

This directory contains the **Next.js 16 App Router** dashboard that visualizes the live simulation.
It connects to the FastAPI backend via REST and WebSockets to stream prices, witness agent activity, and highlight sentiment.

## Architecture Overview

| File | Purpose |
| --- | --- |
| `app/page.tsx` | App Router entry point that loads the `Dashboard` client component. |
| `app/layout.tsx` | Declares metadata + global layout helpers (`globals.css`). |
| `components/Dashboard.tsx` | Orchestrates data fetching, WS reconnection, and composes the premium interface. |
| `components/MarketPulse.tsx` | Displays asset prices, deltas, and the currently selected ticker. |
| `components/RealtimeChart.tsx` | Renders an interactive `lightweight-charts` area chart for the active symbol. |
| `components/AgentRoster.tsx` | Shows the active agents, their persona/model, and ROI badges. |
| `components/SentimentFeed.tsx` | Streams Human-friendly headlines generated by the `JournalistAgent`. |

Styling is powered by [Tailwind CSS 4](https://tailwindcss.com/) and uses modern CSS custom properties for the neon-dystopian theme.

## Setup

```bash
cd frontend
npm install
```

### Development

```bash
npm run dev
```

Runs the Next.js dev server on [http://localhost:3000](http://localhost:3000). The dashboard expects the backend at `NEXT_PUBLIC_API_BASE`/`NEXT_PUBLIC_WS_URL`.

### Production Preview

```bash
npm run build
npm run start
```

This runs the optimized Next.js server. The Docker production stack proxies the frontend at `/` so it can point to `/api` for the backend.

## Environment Variables

| Name | Description |
| --- | --- |
| `NEXT_PUBLIC_API_BASE` | Base URL for REST endpoints (defaults to `http://localhost:8000`). |
| `NEXT_PUBLIC_WS_URL` | WebSocket URL (defaults to `ws://localhost:8000/ws`). |
| `NEXT_PUBLIC_API_KEY` | Optional API key forwarded in REST headers and as `token` query param for WS connections. |

These values are injected into the `Dashboard` component so the UI can pool state and stream updates.

## How the Dashboard Works

1. **Hydrate** – `Dashboard` fetches `/state` (tickers, sentiment, metrics) and `/agents` once on mount.
2. **Stream** – A resilient WebSocket (`/ws`) sends { ticker, sentiment, metrics, news } payloads that update tables, charts, and the feed.
3. **Presentation** – Panels reuse shared gradients, typography, and `glass-*` helpers from `globals.css`.

## Observability & Testing

- `npm run lint` validates ESLint + Next.js rules.
- The `RealtimeChart` uses `lightweight-charts` for the price area curve.
- Jest/unit tests for the backend propagate data consumed by this UI (see `/reports`, `/logs`).

## Deployment Tips

- In production, the `docker-compose.prod.yml` stack runs this frontend as a standalone container.
- The Nginx proxy rewrites `/api` to the FastAPI backend and upgrades `/ws` for live streaming.
- The frontend dockerfile passes `NEXT_PUBLIC_API_BASE=/api` and `NEXT_PUBLIC_WS_URL=/ws` at build time for seamless internal routing.
